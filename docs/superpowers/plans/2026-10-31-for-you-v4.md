# For You v4 Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the For You tab as the approved v4 design: Apple-principle structure and copy, Material 3 Expressive components, existing long-press sheet kept.

**Architecture:** A pure `ForYouSections` builder turns `RecommendationUiState` into an ordered list of sections (carousel, more-like, authors, AI, top genre, something different, just added, browse genres); `RecommendationTab` renders that list with new focused composables. Engine/VM keep their data flow; only row titles, reasons and copy change there. All copy lives in one `ForYouCopy` object so the deck is applied in one place.

**Tech Stack:** Kotlin, Jetpack Compose, `androidx.compose.material3:material3:1.5.0-beta02` (Expressive APIs, `@ExperimentalMaterial3ExpressiveApi`), Coil 2, JUnit4.

**Spec:** `docs/superpowers/specs/2026-10-31-for-you-v4-design.html` (phones 1–4 + "Material 3 Expressive parts used" + "Copy rules" + "Copy deck: old → new").

## Global Constraints

- Material 3 version: `1.5.0-beta02` (app-wide, `gradle/libs.versions.toml` `androidx-compose-material3`).
- Section order (hide any empty one): Top Picks carousel → "More like [X ▾]" → "By authors you like" → "✦ Picked by AI" → "Top {genre} for you" → "Something different" → "Just added" → "Browse by genre".
- Copy: sentence case everywhere; never the words pool, indexed, seeding, providers, budget, tags, match %; strings exactly as in the spec's copy deck.
- One action name each: "Not for me" (one novel), "Hide everything by this author" (author), "Hidden" (where to undo).
- No badges, % or ✕ on covers. Tap = open; long-press = existing `NovelActionMenu` sheet.
- Covers 16dp corners; carousel items 28dp masks; genre tiles use `MaterialShapes` (Cookie9Sided, Sunny, Clover4Leaf, Pill, Arch, Gem) cycled in that order.
- Line under a cover: AI row = reason; authors row = author; every other row = source name.
- Snackbars: "Got it, you won't see \"{title}\" again" / "You won't see novels by {author}", both with action "Undo".
- Pull-to-refresh kept. Background discovery unchanged.

## Review Focus

- Empty library + no AI key: screen shows only the first-time empty state ("Your picks will show up here" + "Find novels"), no blank rows — test in Task 2.
- AI rows: AI picks and AI discovery both present, overlapping novel → shown once, picks first — test in Task 2.
- "More like" switcher with only one seed: chip shows no ▾ and no menu — test in Task 2 (`switcherOptions.size <= 1`).
- Very long titles (60+ chars, e.g. "The Years of Apocalypse - A Time Loop Progression Fantasy (Book 1-2 stubbed!)") clamp to 2 lines in rows and carousel; "More like" chip ellipsizes but keeps ▾ — verify on device in Task 6.
- Material 3 upgrade regressions on other screens (Library, Browse, Details, Reader, Settings): visual check on device in Task 6.
