# History v2 Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the History tab as the approved grouped-card design with Material 3 Expressive components, motion and micro-animations, keeping every current feature.

**Architecture:** A pure `HistorySections` builder turns history items + library lookups + query + clock into date-grouped cards of `HistoryRowModel` (titles, short time, chapter line, source · %), unit-tested. The ViewModel adds undoable remove/bulk-remove (restore with original timestamps), add-to-library and copy. `HistoryTab` is rewritten over that model with new focused composables. All strings in one `HistoryCopy` object.

**Tech Stack:** Kotlin, Jetpack Compose, `androidx.compose.material3:material3:1.5.0-beta02` (already in the app; Expressive APIs need `@OptIn(ExperimentalMaterial3ExpressiveApi::class)`), Room, JUnit4.

**Spec:** `docs/superpowers/specs/2026-10-31-history-design.md` (+ the two HTML mockups it names).

## Global Constraints

- Every string comes from `HistoryCopy` and matches the spec's Copy section exactly; sentence case.
- No progress bar anywhere; progress is text ("Source · N%", "N% read · 5h ago").
- Rows have no buttons; tap = continue reading at `chapterUrl`; long-press = compact sheet.
- Removing from history never deletes read chapters; Undo restores the same history rows with their original timestamps.
- Only "Clear history" asks for confirmation; single and bulk remove use Undo snackbars.
- Motion: History content runs under `MotionScheme.expressive()`; rows/headers use `animateItem()`; the micro-animations listed in the spec's "Motion & micro-animations" section are required.
- Material 3 Expressive components as listed in the spec's "components" section; do not hand-roll a component the library provides.
- Phone for device work: `adb -s "$(adb devices | awk 'NR>1 && $2=="device"{print $1}' | head -1)"`; never uninstall the app; restore any user data you change.

## Review Focus

- Undo after swipe-remove restores the row in its original date group and position (original timestamp), not at the top as "Just now" — test in Task 2.
- Bulk remove of every item in a group: that group's card disappears; Undo brings it back — test in Task 1 (builder drops empty groups) + Task 4 device.
- Items whose novel isn't in the library (no total/progress): line 3 shows source only; sheet shows "{chapter} · {source}" and no "% read" — test in Task 1.
- Time labels at boundaries: 23:59 yesterday vs 00:01 today; a date 6 days ago vs 8 days ago; a date last year shows the year — test in Task 1 with an injected clock.
- Search with regex/special characters ("(", "*", "\") and mixed case highlights correctly and doesn't crash — test in Task 1.

- `data class HistoryRowModel(val item: HistoryItem, val title: String, val time: String, val chapterLine: String, val metaLine: String, val progressPercent: Int?, val inLibrary: Boolean, val titleMatch: IntRange?)`

- `fun shortTime(timestamp: Long, now: Long, zone: ZoneId, use24h: Boolean): String`
- `fun sheetMeta(row: HistoryRowModel): Pair<String, String?>` → (line "Ch. {n} of {total} · {source}" or "{chapter} · {source}", optional "{N}% read · {time}" or just time).
- `object HistoryCopy` — every spec string (`fun subtitle(n)`, `fun removedOne(title)`, `fun removedMany(n)`, `fun removeN(n)`, `fun selected(n)`, `fun results(n)`, `fun noMatch(q)`, `fun clearBody(n)`, …).
